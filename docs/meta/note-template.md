# Note template

Copy the block below into a new file, fill it in, and add the note to its hub ([[note-rules]]).

```markdown
---
title: <Title>
status: planned
tags: [<hub-name>]
up: "[[<hub-name>]]"
updated: <YYYY-MM-DD>
---

# <Title>

<One or two sentences: the single idea this note holds.>

<Details: rules, examples, code.>

## Related

- [[<note>]]
```

For an ADR, use the sections Context, Decision and Consequences instead (see [[decisions]]).
